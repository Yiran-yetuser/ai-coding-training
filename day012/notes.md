## Coding Skill

NumPy 配对索引与重复位置的向量化累加，用于构造固定类别数的混淆矩阵。

## 出现的问题

用户自述首版写成了 `counts = np.add.at(counts, (y_true, y_pred), 1)`。`np.add.at` 会原地更新数组，但返回 `None`；这个赋值会在数组更新后，让变量 `counts` 重新指向 `None`。

当前代码已改为单独调用 `np.add.at(...)`，再返回 `counts`，Review 未发现功能错误。两个题目样例和空标签数组检查均通过，覆盖重复类别对、未出现类别、单个样本、固定 shape、`np.int64` 和输入内容不变。

## 值得记住的 Pattern

阅读 API 时分别确认“是否修改输入”和“返回什么”。原地修改不代表一定返回修改后的数组。

`(y_true, y_pred)` 将两个索引数组按位置配对；多个样本指向同一格时，`np.add.at` 会逐次累加，不能默认普通高级索引的 `+=` 具有相同效果。
