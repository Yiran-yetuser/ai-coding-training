## 2. 必要背景

图像分类等 CV 流程通常先把解码后的像素数组交给模型，像素常以 `uint8` 保存，范围是 0～255。模型预处理往往会把像素变成浮点数，再缩放到 0～1；转换和运算的顺序会影响 dtype，也会影响是否能原地写回。题目中的函数接收一张 `uint8` 图像，返回 shape 相同的 `float32` 新数组，并保持输入不变。这里仅练习像素类型与范围转换，不做通道重排、均值方差归一化或模型推理。

## 3. 小例子

```text
输入 dtype：uint8       输出 dtype：float32
像素：[0, 128, 255]  →  [0.0, 约 0.502, 1.0]
```

灰度图和 RGB 图的 shape 都应保留；本题不改变像素排列。

## 4. Coding 任务

阅读并 Debug 这个 CV 输入预处理函数：

```python
import numpy as np


def preprocess_image(image):
    image /= 255.0
    return image.astype(np.float32)
```

修改函数，使它能处理本题约定的 `uint8` 图像，返回新数组且不修改输入。保留函数名和参数；可以用断点或临时打印查看运算前后的 dtype、shape，不调用现成的图像预处理流水线。

输入可以是 shape `(H, W)` 的灰度图或 `(H, W, 3)` 的 RGB 图，像素 dtype 为 `np.uint8`，各维度均非空。不要求处理其他 dtype、非法 shape 或数值范围。
